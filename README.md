# Portafolio / Portfolio · Johan Torres

**Diseño de marca × desarrollo web.** Marcas atrevidas, construidas con ingeniería.
**Brand design × web development.** Brands that dare, built with engineering.

## Dos formas de verlo · Two ways to see it

| | |
|---|---|
| **Universo 3D** (`/`) | La portada cae y se vuelve el piso de un universo. Cubo, el personaje, camina por los cuatro mundos (FutPlay, Paws of Malta, Frank's Hotdogs y Boom ICE), Mi historia y Hablemos. Hecho con Three.js en un solo HTML. |
| **Portafolio 2D** (`/2d`, `/2d/en`) | Los mismos mundos como páginas web normales, para leer con calma o compartir un proyecto. |

Los dos tienen español e inglés y un botón para pasar de uno al otro.
Both have Spanish and English and a button to switch between them.

## Controles del universo · Universe controls

- **W / ↑** avanzar · **S / ↓** retroceder · **A D / ← →** girar · **Shift** correr · **Espacio** saltar · **H** saludar
- **Doble clic** en el piso: Cubo camina hasta ahí · **V** cambia de cámara · **M** prende la radio
- **E** siguiente · **Q** anterior · en el celular, controles táctiles en pantalla

## Radio

La radio retro reproduce la playlist *Obra ruidosa* con el reproductor de Spotify dentro del universo. Spotify da las canciones completas a quien tiene sesión iniciada en el navegador; si no, adelantos de 30 segundos.

## Estructura · Structure

```
index.html        universo 3D (Three.js r128)
pasos/ pasos-en/  pantallas de cada mundo (ES / EN)
piso/             piso en relieve de Mi historia
2d/  2d/en/       portafolio 2D (ES / EN)
assets/           imágenes del portafolio 2D
```

Sitio estático: no necesita compilar. Static site, no build step.
